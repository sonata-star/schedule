# Расписание — нативная версия на Kotlin

Проект Android Studio, перенесённый с предоставленных исходников Expo / React Native на Kotlin + Jetpack Compose.

## Как открыть и собрать APK
1. Распакуйте архив.
2. Откройте папку `to-do-kotlin` в Android Studio.
3. Дождитесь Gradle Sync. Для проекта нужен JDK 17 и Android SDK Platform 35.
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK обычно появится в `app/build/outputs/apk/debug/app-debug.apk`.

Пакет: `com.todo.app`. Минимальная версия Android: API 24. Версия: `1.0.0`.

## Перенесено
- главный экран расписания и русские названия дней;
- автоматический выбор текущего дня, воскресенье отображается как суббота;
- карточки уроков со статусами текущий / следующий / прошедший;
- отображение минут до ближайшего урока;
- добавление предмета сразу на несколько дней;
- редактирование и удаление всех записей предмета;
- SQLite и настройка длительности новых уроков;
- тёмная и светлая темы;
- очистка расписания и версия в настройках.

## Что ещё не перенесено в эту первую версию
- автоматические уведомления за 10 минут до урока;
- автоматические внешние резервные копии, которые сохраняются после удаления приложения;
- поля кабинета и преподавателя в форме редактирования.

Это честный первый перенос основного приложения, а не готовый APK. В среде подготовки нет Android SDK/Gradle, поэтому сборка здесь не выполнялась. После открытия проекта в Android Studio нужно выполнить Gradle Sync и собрать APK.
